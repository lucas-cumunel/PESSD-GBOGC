# PESSD-Gender Biases in Olympic Games Commentary

To have the NLP course version, please go to the NLP branch

## Reproducing the results

**Descriptive analysis** — download the data, install dependencies, and generate plots and tables:
run `data_download.ipynb` then `descriptive.ipynb`

**Topic analysis** — unsupervised topic modeling and rare topic search:
run `topic_modeling.ipynb` then `dictionnaire.ipynb`


For csv data download → data_download.ipynb\
For descriptive statistics → descriptive.ipynb\
For wav to transcription conversion → transcription_diarization_genre.ipynb\
For unsupervised topic modeling → topic_modeling.ipynb\
For top words cosine distances → cosinus.ipynb
